# Greedy Algorithm Simulator

An interactive web application that demonstrates how Greedy Algorithms work through step-by-step visualizations.

## Features

- **Activity Selection:** Visualizes selecting compatible activities.
- **Fractional Knapsack:** Demonstrates maximizing value using a greedy strategy.
- **Huffman Coding:** Visualizes Huffman tree construction and code generation.
- **Interactive Controls:** Play, Pause, Resume, Next Step, and Reset.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Explore the three algorithm simulations.

## Purpose

This project was developed to improve understanding of greedy algorithm concepts through interactive visualization.
